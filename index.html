📖 문장온 사용 설명서

처음 사용하는 분들을 위한 안내입니다.

1. 프로그램 소개

문장온은 사용자가 작성한 글의 감정과 분위기를 분석하고, 반복되는 단어와 개선 표현 및 비유 문장을 추천하는 글쓰기 보조 프로그램입니다. 학생, 글쓰기 초보자, 작가 지망생 등 자신의 문장을 더 풍부하게 표현하고 싶은 사람에게 유용합니다.

2. 접속·설치 방법

문장온은 별도 설치가 필요 없는 웹 앱입니다. GitHub Pages에 배포된 문장온 주소를 인터넷 브라우저에서 열면 바로 사용할 수 있습니다. 현재 버전은 설치형 PWA가 아니므로 별도의 설치 과정은 필요하지 않습니다.

3. 화면 설명

① 문장 입력칸: 분석하고 싶은 글을 입력합니다.

② 문장 분석하기 버튼: 입력한 글을 분석합니다.

③ 분석 결과 영역: 감정, 분위기, 단어 사용 빈도, 문장 개선 결과와 비유 표현을 보여줍니다.

4. 기능별 사용 방법

기능 1. 감정 및 분위기 분석

문장 입력칸에 글을 작성하고 분석하기 버튼을 누릅니다. 감정 분석 결과와 감정별 비중 그래프, 글의 분위기를 확인합니다.

기능 2. 단어 사용 분석

글을 분석한 뒤 단어 사용 분석 영역을 확인합니다. 자주 등장한 단어와 사용 횟수를 그래프로 살펴볼 수 있습니다.

기능 3. 문장 개선 및 비유 표현 추천

분석 결과에서 원본 문장과 개선 문장을 비교합니다. 이어서 제시되는 비유 표현을 살펴보고 자신의 글에 어울리는 표현을 참고합니다.

5. 주의사항과 자주 묻는 질문

Q. 분석 결과는 항상 정확한가요?

A. 미리 설정한 단어 사전과 규칙을 활용하므로 문맥에 따라 실제 의미와 다를 수 있습니다.

Q. 글을 짧게 입력해도 되나요?

A. 가능하지만 글이 너무 짧으면 분석할 단어가 부족할 수 있습니다.

Q. 입력한 글은 자동 저장되나요?

A. 현재 버전은 입력한 글을 별도로 저장하지 않습니다. 필요한 글은 따로 보관해 주세요.

주의: 분석 결과와 추천 표현은 참고용으로 활용하고, 자신의 글의 문맥에 맞게 수정하는 것이 좋습니다.
